Die Desktop-App gibt es nur für Windows. Luvina läuft auch im Browser.

Der Download startet. Öffne danach die Datei Luvina-Setup.exe, um Luvina zu installieren.

So kommt Luvina auf deinen PC

  1. Herunterladen

    Lade die Datei Luvina-Setup.exe herunter.

  2. Installieren

    Öffne die Datei. Zeigt Windows eine blaue Warnung, klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“. Die App ist noch nicht digital signiert.

  3. Starten

    Luvina findest du danach im Startmenü und auf dem Desktop.

Anbindung an MSFS 2024

Das Plugin, das Flugdaten live aus dem Simulator liefert, ist in Arbeit. Es kommt als Update in dieselbe App.

Häufige Fragen

Muss ich die Desktop-App nutzen?

Nein, Luvina läuft auch im Browser. Die Desktop-App öffnet es in einem eigenen Fenster und richtet später das MSFS-Plugin für dich ein.

Warum zeigt Windows eine Warnung?

Das passiert bei jeder neuen Software ohne digitale Signatur. Du lädst die Datei direkt von GitHub herunter. Klicke auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.

Welche Windows-Version brauche ich?

Windows 10 oder 11, jeweils 64 Bit.

Wie aktualisiere ich Luvina?

Die Inhalte der App aktualisieren sich von selbst. Gibt es eine neue Version der App selbst, lädst du sie hier erneut herunter und installierst sie über die alte.

Wie deinstalliere ich Luvina?

Öffne die Windows-Einstellungen, wähle „Apps“, dann Luvina und „Deinstallieren“.

Bereit für die nächste Landung?
